**小径分岔的未来**

**Forking Paths To The Future**
-----------------------
“穿过可能性的花园，成为自己。”

这个游戏的灵感来自于博尔赫斯的短篇小说《小径分岔的花园》：这个故事重要的美学特征之一，就是时间在意识概念中的非线性。我们说出“将来”的时刻，依旧是此刻；我们对于“将来”的祝福，已经是未来。

游戏共两周目，五个结局。当你完成全部流程，走到花园的出口，会听到一首小小的、轻盈的歌曲（不包括小红书小工具版本）。

祝大家游玩愉快！
