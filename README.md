# 姜崃漫游 · PC 网页拆分版

文档日期：261013　版本：AMD#1　游戏版本：261013 AMD#33

本版从PC AMD32单文件无损拆分，保留原图片、音乐、字体、剧情、存档与调试功能。固定16:9横版，结局进入流程图使用1秒渐变。首页约150 KB，40个独立资源共约39.18 MB，最大单资源约3.51 MB，无需安装依赖。

在线试玩：https://skrikkk.github.io/jianglai-vn-demo/

下载仓库ZIP并完整解压后，Windows双击根目录的`试玩.cmd`，其他系统在浏览器打开根目录`index.html`。必须保留同级`pc-assets`文件夹；单独复制HTML会缺少资源。旧`dist`为九月历史版本。

## 网页上传与后续维护

先上传`pc-assets`目录中的资源，再替换根目录`index.html`、`试玩.cmd`、本说明和`release-manifest.json`。后续只需要上传改变的资源与首页，不必重新上传全部资源。发布完成需等待GitHub Pages部署成功。

资源文件名是内容SHA256前16位，清单记录完整指纹、类型与大小。构建过程可将拆分资源回填并与AMD32原文件逐字比较，确保内容无损。游戏存档仍保留原存储键；实际进度取决于同一浏览器与访问来源。

本版是PC横版测试页，手机/Safari真机兼容性仍需实测。素材未附带再分发许可。
